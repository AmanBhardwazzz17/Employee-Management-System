# Employee Management System

A Python-based Employee Management System built to practice
Object-Oriented Programming (OOP) concepts.

## Features

- Create employee objects
- Display employee information
- Increase employee salary with validation
- Validate salary using a static method
- Change company name using a class method
- Create a Developer class using inheritance
- Override methods using inheritance
- Handle invalid salary increments using exceptions
- Display developer information using __str__()

## OOP Concepts Used

- Classes and Objects
- Constructors (__init__)
- Instance and Class Variables
- Instance Methods
- Class Methods (@classmethod)
- Static Methods (@staticmethod)
- Inheritance
- Method Overriding
- super()
- Exception Handling
- Magic Methods (__str__)

## Requirements

- Python 3

## How to Run

1. Clone or download the project.
2. Open the project directory.
3. Run the following command:

   python3 main.py
